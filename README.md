### Compare and contrast One Hot and Binary encodings

One hot uses a flip flop for every state while binary encoding uses less flip flops
for log2Nstates. One hot logic is simpler while binary is more complex combinational logic.

### Which method did your team find easier, and why?

We found that the one hot was a bit easier to understand and code. Mainly the logic
was much easier to implement over Binary encoding.

### In what conditions would you have to use one over the other? Think about resource utilization on the FPGA.

You would use Binary over One hot when you have less resources like on a FPGA board and have to use less flip flops.
One hot is used with enough resources and easier logic. So it's like choosing efficiency or speed.
